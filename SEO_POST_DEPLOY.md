# SEO post-deployment checklist

1. Deploy the changes to GitHub Pages.
2. Add `notdavidmill.dev` as a Domain property in Google Search Console.
3. Submit `https://notdavidmill.dev/sitemap.xml` in Google Search Console.
4. Use URL Inspection and request indexing for:
   - `https://notdavidmill.dev/`
   - `https://notdavidmill.dev/about/`
   - `https://notdavidmill.dev/publications/`
   - `https://notdavidmill.dev/presentations/`
5. Add `https://notdavidmill.dev/` as the primary website URL on:
   - Google Scholar
   - GitHub
   - LinkedIn
   - University of Rochester profile or laboratory profile
   - ORCID, if applicable
   - Conference and author profiles, where editable
6. When linking to the site, prefer descriptive text such as `David Millard` or `David Millard's research website`.
7. Check Google periodically with:
   - `"David Millard" "University of Rochester"`
   - `"David Millard" machine learning`
   - `site:notdavidmill.dev`

Indexing and ranking changes are not immediate or guaranteed.
